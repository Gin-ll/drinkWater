## 1. 项目概况

纯本地 Android 喝水提醒与管理 App，无后端、无账号。

- **核心场景**：设置喝水提醒 → 到点系统通知 + 小米手环震动 → 在手机/首页标记「已喝」→ 统计喝水情况。
- **交互基调**：简约小清新、全中文界面、24 小时制。
- **运行环境**：Flutter 3.44 / Material 3 / Android 7.0+（minSdk 24）/ 小米真机 + 手环保真链路。

## 3. 功能清单（按模块）

### 3.1 首页 · 今日喝水时间轴
- 顶部**日期栏**：`M月D日 星期X`，可 `◀ ▶` 切换前后日期，点击中间回到今天。
- 主体**时间轴**：每个已设提醒一行 = `左侧时间 + 标题 + 状态胶囊`。
  - 状态二值化：**已喝水**（有 drank 记录）/ **未喝水**（其余）；未来时刻显示**待提醒**。
  - 未喝水时右侧展示「杯中有水」**图标**（颜色跟随主题），点击标记已喝。
  - 仅今天可标记：查看其他日期点图标 → 顶部提示「仅今天可标记已喝」，状态不变。
- **左滑操作**：滑出「编辑 / 删除」两个图标（同一时刻只允许一个卡片滑开）；删除带二次确认。
- 点卡片本体 → 编辑弹窗。
- **手动喝水记录**：流水记录（reminderId 为空）也出现在时间轴，点按 → 弹窗「改记录时间 / 删除」。
- **底部「喝水」按钮**（仅今天显示，定高 50）：点击按当前时间记录一杯水，顶部提示「已记录一杯水 💧」，统计即时 +1。
- 循环提醒从**创建当天**起算（startOn），创建前的历史日期不回填。

### 3.2 新建 / 修改提醒（弹窗）
- 标题：默认「喝水提醒」，点击聚焦自动全选，直接输入即替换；不修改即为该标题。
- 循环：**仅一次 / 每天 / 每周（星期多选）/ 每月（日期、月末兜底）**。
- 时间：底部弹窗，默认输入模式，可**键盘输入 + 滚轮选择**双向联动（24 小时制）。
- 仅一次：日期**默认今天**。
- 校验与拦截：
  - 标题非空；
  - 提醒时间不能早于当前时间；
  - 每周至少选一天；
  - 一次性时间必须晚于当前；
  - **同刻去重**：当天该时刻已有启用提醒 → 弹「是否仍要添加」确认。
- 保存后关闭弹窗，顶部提示，列表/统计即时刷新。

### 3.3 统计页
- **范围**：周 / 月（已移除年）。
  - 周：标签显示「第X周」（ISO 周数）；月：`2026年8月`。
  - 顶部布局：`周期切换 | ◀ 区间时间 ▶`（时间标签居中可省略）。
- **汇总卡**：本周/月喝水总数 + 单日最高。
- **每日喝水统计**（单卡片，右上角 柱状/折线 切换）：
  - 周 X 轴：周一~周日；月 X 轴：几号。
  - 月视图可**横向滚动**；顶部 X 轴已去除。
  - **点选柱子/折线点** → 提示当天 + 次数（如 `周三 / 3 次`、`8月20日 / 4 次`）。
- **日历**：
  - 周视图：只展示当周 7 天；月视图：整月。
  - 点某一天 → **两行式弹窗**：第 1 行 `标题(左) + 状态(右)`；第 2 行 `设置喝水时间(左) + 记录喝水时间(右)`。
- 数据变化**实时刷新**（监听全局状态）。

### 3.4 我的（设置）
- **外观-主题色**：蓝 / 绿 / 黄 整行切换按钮（标题独立一行不换行），全局即时生效。
- **免打扰**：开关 + 起止时间（24 小时制、支持跨午夜）；时段内提醒**完全跳过、不补推、不记录**。
- **小米适配引导**：通知权限 / 精确闹钟 / 电池优化 / 自启动（状态打勾 + 一键跳转，失败降级图文）+ 小米运动健康绑定与「消息通知」图文指引。
- **排查顺序**自诊清单（手机不响 / 手机响手环不震）。
- 关于：版本、本地存储说明。

### 3.5 通知与手环保真链路
- 到点由**系统精确闹钟**直接弹「喝水提醒」通知，带「**已喝水**」操作按钮（仅保留已喝按钮）。
- 手机或手环点按钮 → 后台 isolate 写一条 `drink_logs`（drank），首页/统计即时反映。
- 通知渠道「喝水提醒」（重要度高、默认提示音+震动）。

### 3.6 全局体验
- **顶部轻提示**（白底+边框+阴影+主题色图标，rootOverlay 置顶）用于成功/校验类消息。
- 全中文（含日期/时间选择器等内置控件中文化）。
- 首次启动（空库）自动写入 6 条示例每日提醒，仅一次。

## 4. 数据模型（drift）

**reminders（提醒）**
| 字段 | 说明 |
|---|---|
| id / title / body | 主键 / 标题 / 正文（表单已不录入，历史保留） |
| repeatType | 0 仅一次 · 1 每天 · 2 每周 · 3 每月 |
| hour / minute | 触发时间分量 |
| weekdays | JSON `[1..7]`（每周型） |
| monthDay | 1..31（每月型，不足取月末） |
| triggerAt | 一次性绝对时间戳 |
| enabled | 启用开关 |
| createdAt / updatedAt | 创建/更新时间（createdAt 兼作循环起始日） |

**drink_logs（喝水记录）**
| 字段 | 说明 |
|---|---|
| id / reminderId | 关联提醒（null=手动喝水） |
| actionTime | 点按时刻（记录喝水时间） |
| occurDate | 归属日期 `YYYY-MM-DD`（统计口径） |
| isDrank | 1 已喝 / 0 未喝 |

**settings（键值）**：themeColor、dndEnabled、dndStart、dndEnd、seeded（示例数据已写入标记）

## 5. 调度与通知设计（重要）

- **仅当天设闹钟**：每次全量刷新 = 取消旧闹钟 → 仅当「今天」匹配某提醒规则（循环/一次性）且时刻未错过、不在免打扰窗口内，才注册 **1 个当天一次性精确闹钟**。
- 过去 = 仅保留数据；未来日期不预排（闹钟数≈当天待触发数，远离安卓 500 并发上限）。
- **含义**：循环提醒的再次触发依赖「新的一天打开 App 重排」或「开机广播恢复」（`ScheduledNotificationBootReceiver`）。
- 点「已喝」通知按钮的后台回调：从通知 payload 取 `reminderId / occurDate / dbPath` → 后台 isolate 打开 drift 写库（无需平台通道猜路径）。
- 权限矩阵：POST_NOTIFICATIONS、SCHEDULE_EXACT_ALARM、RECEIVE_BOOT_COMPLETED、REQUEST_IGNORE_BATTERY_OPTIMIZATIONS。

## 8. 真机验收待办（实机清单）
